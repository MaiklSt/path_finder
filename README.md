# Path finder

Shortest Path Finder

Flutter-додаток для пошуку найкоротшого шляху на квадратній сітці з урахуванням заблокованих комірок.

## Основний функціонал

Основний функціонал
Налаштування API URL.
Отримання завдань із сервера.
Розрахунок найкоротших шляхів.
Відправлення результатів на сервер.
Перегляд списку результатів та візуалізація знайдених шляхів на сітці.

## Технології

Flutter,
Dart,
HTTP API
